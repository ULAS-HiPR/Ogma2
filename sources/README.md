# Ogma 2 source evidence

Only source files required to understand a current Ogma 2 decision belong here.

| Source | Role |
| --- | --- |
| [`project/ogma-rev1/`](project/ogma-rev1/) | Decision-relevant Rev 1 flight closure, prior requirements, integration/HIL checks, selected plots, photographs, and plotbooks |
| [`inspiration/hardware-comparison/`](inspiration/hardware-comparison/) | Four CATS Vega and Fluctus photographs supporting geometry, access, connector, and serviceability observations |
| [`inspiration/cats-configurator/`](inspiration/cats-configurator/) | Seven selected CATS Configurator screens supporting identity, readback, sequence, preflight, and test-mode observations |

These images are evidence of visible geometry and interaction design only. They
do not establish electrical performance, fault cause, qualification, safety, or
fitness for Ogma.

The Rev 1 package is a read-only evidence copy. The original Ogma workspace and
repositories remain separate and authoritative for their own implementation and
history.

The complete original four-photo and eleven-screen capture remains outside this
repository in the local sibling
`archive/sources/design-inspiration-originals/`. Duplicate UI states were not
copied into the clean clone. Original filenames and hashes are recorded in the
source-specific READMEs.

Provenance and reuse rights remain unresolved. The repository is private; do not
publish these images outside internal project review until their source and
permission are established.
