# Ogma 2 source evidence

Only source files required to understand a current Ogma 2 decision belong here.

| Source | Role |
| --- | --- |
| [`project/ogma-rev1/`](project/ogma-rev1/) | Decision-relevant Rev 1 flight closure, prior requirements, integration/HIL checks, selected plots, photographs, and plotbooks |

The Rev 1 package is a read-only evidence copy. The original Ogma workspace and
repositories remain separate and authoritative for their own implementation and
history.

The CATS Vega and Fluctus photographs and CATS Configurator screens once kept
here were removed on 22 November 2026 when the repository went public: their
reuse rights were never established. The observations drawn from them stay in
the documents that cite them.
