# Art for Burrito's back silkscreen (D-22Nov.12)

- `ulas-hipr-logo.png`: the ULAS HiPR logo, the team's own, from the website repository
  `github.com/ULAS-HiPR/ulas-hipr.github.io`, fetched 22 November 2026. Every opaque pixel that isn't black is
  traced as ink.
- `fonts/`: the typeface for the name; see its README.

Everything else on the back (the burrito rocket, the waves, the Ogham line) is drawn from code in
`tools/layout/engine/art.py`. The texts and anchors are in `../spec.py` under `ART`.
